# Project color guide

Derived from the attached NYC.gov / ACCESS NYC reference. Use these for all assets in this project.

## Core
- Navy (primary): `#1B2E7F` — headers, primary buttons, links
- Ink (near-black): `#0D0D0D` — top/bottom bars, primary text
- Paper: `#FFFFFF` — surfaces
- Off-white: `#F4F5F7` — app background, cards on white

## Brand accents (from the NYC wordmark)
- Cyan blue: `#1E9BE0`
- Green: `#00A550`
- Amber (use sparingly, status only): `#F2B21B`

## Grays
- Border: `#D6D8DE`
- Muted text: `#5A5F6B`

## Rules
- Max 2 accents per screen; navy carries the identity.
- Text on navy is always white; never navy text on green/cyan.
- Modern mobile: generous spacing, 16px+ radii on cards, 44px min hit targets, no gradients.
