# laser-4up-clean

**Layout:** A plain laser print, four copies to one sheet (Copy B, C, 2, 2).

**Capture:** A flatbed scan. The control, and the best input this app will ever get.

**Employee:** DANIEL OKONKWO — HARBORLIGHT LOGISTICS LLC

## What this case checks

- The same figures appear FOUR times. An engine must return one W-2, not four merged.
- A parser anchored on "the value below the Box 1 label" will find four of them.
- Two state rows, NY and NJ — the row-repetition case.
- Small type: this is where digit transposition shows up first.

Not printed on this layout, so `expected.json` leaves it null: `box14_other`.
